# Training log

**Why keep one:** memory lies. A dog that "never improves" often shows steady progress in a log, and a dog that "is fine" often shows a pattern you missed. Two lines after each session is enough.

## Session log

Copy this table into a notebook, a note on your phone, or a spreadsheet. One row per session.

| Date | What we worked on | Where | Minutes | How many tries | How many right | Dog's state before (relaxed / quiet signals / over) | What I will change next time |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Two habits that make the log useful:
- Fill in "what I will change" every time, even if it is "nothing".
- Once a week, read the last seven rows and look for a pattern.

## Weekly check-in

Answer these once a week in two or three lines each.

1. What got easier this week?
2. What got harder, or stayed stuck?
3. Did the dog have any "big" days (vet, visitors, storms) that could have stacked stress?
4. Is the dog sleeping enough?
5. What is the one thing to focus on next week?

## Puppy socialization checklist

Tick each item when the puppy has met it and ended calm or curious. Aim for a few new ticks a week during the window (up to about 14 weeks), then keep going more slowly.

| People | Dogs and animals | Places and surfaces | Sounds | Handling |
|---|---|---|---|---|
| Men, women | Calm adult dogs | Grass, gravel, sand | Traffic | Paws held |
| Children of several ages | Puppies in class | Metal grates, stairs | Vacuum | Ears touched |
| Hats, hoods, sunglasses | Cats (at a distance) | Car rides | Doorbell | Mouth opened |
| Beards, uniforms | Livestock (if relevant) | Elevator, vet lobby | Thunder (recording, low) | Collar grabbed |
| Wheelchairs, bikes, joggers | | Busy street (from a distance) | Fireworks (recording, low) | Brushed, towel-dried |
| Delivery person | | Water, puddles | Kitchen appliances | Lifted, carried |

## Behavior problem baseline

Before starting any problem page, record where you are so you can see change.

| Problem | Trigger | How close or how long before the dog reacts | How bad (1 to 5) | How long to recover | Date |
|---|---|---|---|---|---|
| | | | | | |

Re-measure every two weeks. The number that moves (distance, seconds, recovery time) is your proof.
