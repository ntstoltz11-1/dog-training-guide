# Comparison method

How to run and record a fair comparison between two training approaches for one behavior. The reader-facing version is `guide/06-tools/method-comparison-worksheet.md`; this file holds the design rules an agent applies when helping a reader set one up or when writing a comparison into the guide.

## Design rules

1. **One behavior, one primary outcome.** Define the behavior so two people would agree whether it happened (for example, "dog's front feet reach handler within 5 seconds of the cue").
2. **Baseline first.** At least 3 sessions measured before any change.
3. **Pick a design that fits:**

| Design | Use when | Weakness |
|---|---|---|
| Reversal (A-B-A-B) | Testing a management or environment change that can be undone | Learning cannot be reversed; not for skills |
| Multiple baseline across behaviors or settings | Comparing a method across several behaviors | Needs several behaviors of similar difficulty |
| Alternating treatments | Two methods, each tied to its own cue or behavior | Methods can bleed into each other |
| Group comparison | Several dogs available; randomize | Rarely practical for one owner |

4. **Hold these constant:** trainer skill, total training time, reward value, session spacing, environment.
5. **Measure welfare as well as success.** Stress behavior count per session at minimum. Salivary cortisol and cognitive bias tests exist but are rarely practical at home.
6. **Follow up at 4 weeks or more** for retention and in at least one new setting for generalization.
7. **Report ranges, not single numbers.** Session-by-session values, not averages alone.
8. **Blind the scorer if possible.** A second person rating video without knowing which method was used.

## What the published comparisons did (for reference)

- The strongest field comparison randomized dogs to groups, had all dogs wear the same equipment so observers were blind, measured response latency and first-cue compliance, and recorded stress behaviors from video. It was still criticized for trainer-skill confounds and for a handler change midway. Copy the blinding; avoid the confounds.

## Recording

Results of any comparison run through the guide go in a dated file under `research/` with the status banner "comparison, n = 1" and are never generalized into a claim grade above Thin.
